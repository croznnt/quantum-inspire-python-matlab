## 🎯 What this repository contributes

Model spin dynamics and explore the optimal-control module in a MATLAB workflow.

## 🧪 Suggested first exercise

Follow an upstream small-spin example, then inspect a GRAPE objective and its pulse penalties.

This is a proposed starting task. Consult the upstream README, examples and supported dependencies for executable instructions.

## ✅ What to check

Check the upstream MATLAB release, required toolboxes, relaxation model and spin basis.

## 🔎 Scope and limitations

The original Spinach paper describes simulation foundations; current control features extend beyond that paper.
