## 🎯 What this repository contributes

Study Krotov updates with objectives defined through states and target transformations.

## 🧪 Suggested first exercise

Run a documented state-transfer example, then vary the update strength while keeping the physical model fixed.

This is a proposed starting task. Consult the upstream README, examples and supported dependencies for executable instructions.

## ✅ What to check

Inspect discretization, running costs, convergence assumptions and supported QuTiP versions.

## 🔎 Scope and limitations

Monotonic convergence under stated assumptions does not guarantee a global optimum or hardware feasibility.
