## 🎯 What this repository contributes

Use upstream notebooks to learn model construction, propagation and associated quantum tools.

## 🧪 Suggested first exercise

Select one dynamics notebook and reproduce its figures in an isolated matching environment.

This is a proposed starting task. Consult the upstream README, examples and supported dependencies for executable instructions.

## ✅ What to check

Inspect notebook age, dependency versions, execution order and random seeds.

## 🔎 Scope and limitations

A changing tutorial collection is not a frozen reproduction artifact for every QuTiP paper.
