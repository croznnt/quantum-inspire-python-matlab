## What this repository contributes

Explore GOAT and JOPT for analytic controls and compare with GRAPE or CRAB through qtrl.

## Suggested first exercise

Solve the same one-qubit gate problem using an analytic pulse and a discretized pulse.

This is a proposed starting task. Consult the upstream README, examples and supported dependencies for executable instructions.

## What to check

Record parameter scaling, optional dependencies, integration tolerances and total evaluations.

## Scope and limitations

The package builds on qutip-qtrl; do not treat all exposed methods as independent implementations.
